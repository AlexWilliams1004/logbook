# logbook App

I created this project to build a logbook app using 
Python and kivy for the GUI. While working at 
Domino's, I want to be able to track my distance
travelled in kilometers for tax purposes.

The purpose of this project is to determine if
it is possible to build an entire app, from backend
to front end, that can be deployed on my android 
device for testing. 

## Project Focus
-Build a working mobile application using 
Python exclusively.

## Application Requirements
-Track distances travelled using GPS
-Export data summary to csv

## Tools Used
-Python (PyCharm IDE)
-Kivy
-Git & GitHub
